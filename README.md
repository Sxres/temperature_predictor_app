# Temperature Prediction App

![image](https://github.com/user-attachments/assets/40289bf9-9fd1-4ed4-8e0a-b92018f1616a)


This project predicts **local temperatures in Oshawa** using a regression-based **XGBoost model** trained on historical weather station data. The app provides both backend inference and a simple frontend for users to visualize predictions and trends.

---

## 🚀 Features
- Data preprocessing (cleaning, feature engineering, handling missing values).
- Regression model using **XGBoost**, evaluated with **RMSE, MAE, and R²**.
- Feature importance visualization with **SHAP** and time-series trend plots.
- Full-stack deployment with **FastAPI** (backend) + **Streamlit** (frontend).
- Containerized with **Docker** and deployed on **Google Cloud Run**.

---

##  Tech Stack
- **Languages & Libraries:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Plotly, SHAP  
- **Frameworks:** FastAPI, Streamlit  
- **Deployment:** Docker, Google Cloud Run
